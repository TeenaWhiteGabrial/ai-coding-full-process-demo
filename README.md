code下面存放所有模板代码。

分为3个部分：前端（包括Nuxt全栈）、后端（Java、NodeJS），分别存放demo项目

前端有3类模板：
    - 管理端模板，Vue3 + Element Plus 等技术，统一封装了Axios、文件上传等。然后根据登录方式，分为对接maxkey登录和自有登录，其他方面相同。
    - 门户端模板，Nuxt4（不包含后端能力，接口使用后端服务），统一封装了Axios、文件上传等。然后根据登录方式，分为对接maxkey登录和自有登录，其他方面相同。
    - Nuxt全栈模板，Nuxt4（包含后端能力，直接对接数据库）

后端有两类模板：
    - 依赖maxkey的那一套，包含基础功能 + maxkey登录相关（参考技术社区服务）
    - 完全独立的那一套，包含文件上传等基础功能。
